## Sobre o projeto

O Game Store é uma loja virtual de jogos desenvolvida utilizando HTML, CSS e JavaScript.

O projeto apresenta jogos em cards, permitindo pesquisar jogos, filtrar por categoria, visualizar detalhes e destacar produtos.

## Funcionalidades

- Listagem de 8 jogos.
- Imagens dos jogos.
- Busca por nome.
- Filtro por categoria.
- Visualização dos detalhes.
- Destaque visual dos jogos.
- Preços em reais.
- Informação sobre disponibilidade em estoque.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- DOM
